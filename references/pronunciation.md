# 多音字审计指南

## 前提
TTS 引擎**无 SSML 注音能力**。发音问题**只能靠换词解决**，不要尝试参数、拼音标注、特殊符号。

## 高风险字（中文 TTS 常见翻车）
| 字 | 易错读法 | 正确读法（教程语境） | 替换方案 |
|---|---|---|---|
| 调 | tiáo | diào（调用） | 直接写"调用" |
| 应 | yīng | yìng（应用） | 写"软件/工具"或"应用程序" |
| 模 | mó | mú（模板） | 写"模版"或改述 |
| 系 | xì | jì（体系） | 通常 TTS 能对，抽查 |
| 行 | xíng | háng（银行） | 写"银行卡"一般能对，抽查 |
| 重 | chóng | zhòng（重要） | 抽查 |
| 长 | cháng | zhǎng（生长） | 抽查 |

## 流程
1. 解说词定稿后，全文扫描上表 + 其他多音字。
2. 高风险词直接**重写句子**，用无歧义表述。
3. 合成后用 faster-whisper 转写抽查（声调可从转写近似判断，最终以人耳为准）。
4. 用户指出的发音问题 → 记入上表 → 下次自动规避。

## 英文词
-  acronym 一律大写拼读预期：AWS、EC2、RDS、VPC、API。
-  混读词（Python/EC2）在 TTS 易走形时，用中文音译替代（"派森"），字幕保留英文原文。
