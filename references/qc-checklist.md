# QC 清单（阶段门禁 + 终检）

**规则：任一门禁不通过，不许进入下一阶段。终检必须跑成品文件。**

## 门禁 G1：解说词
- [ ] 每段有唯一 sid，时长 hint 合理（8-20s）
- [ ] 口语化，无书面语残留
- [ ] 多音字已做第一轮标记

## 门禁 G2：TTS
- [ ] 段尾无 >1.2s 异常静音（pause 扫描报告）
- [ ] faster-whisper 转写抽查：多音字发音正确
- [ ] durations.json 为实测值，非估算

## 门禁 G3：字幕
- [ ] 事件无重叠（程序断言）
- [ ] `\k` 总时长 == whisper 词时长（偏差 <0.05s/事件）
- [ ] 标点与解说词逐字一致（diff 为空）
- [ ] 无撕开的英文词/数字/中文词（程序断言）
- [ ] 无悬空单字事件（程序断言）

## 门禁 G4：封装
- [ ] acrossfade 数量 == xfade 数量（程序断言，防 C3 回归）
- [ ] ffprobe：H.264 + AAC，1920×1080，faststart
- [ ] 总峰值 ≤-1dB，无削波

## 终检（成品文件）
- [ ] 转写**成品音频**：与解说词对齐，漂移 <0.3s
- [ ] 抽帧：无黑帧/闪烁/拉伸/字幕遮挡
- [ ] 边界点（每个 xfade 处）音画同步
- [ ] 音乐不盖人声，无音量突变
- [ ] 人耳听一遍多音字高风险词
